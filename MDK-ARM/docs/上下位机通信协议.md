# STM32—Jetson 连续视觉通信协议

STM32 是任务主控，Jetson 是常驻视觉服务端。STM32 发送 START 后，Jetson 复用已加载模型持续检测并周期上报最新结果；STM32 发送 STOP 后 Jetson 立即停止发送，但继续运行并可接收新的 START。

## 链路与会话

- USART6：115200、8N1、无流控，STM32 RX 使用 DMA Circular + UART IDLE。
- 帧格式：`5A A5 CMD SESSION LEN PAYLOAD CRC16_L CRC16_H`。
- `LEN` 为一个字节；所有多字节整数为小端；CRC16-Modbus 覆盖 `CMD` 至 Payload 末尾。
- STM32 每次有效 START 递增 `SESSION:uint8`。Jetson 回包使用同一 SESSION；STM32 丢弃旧 SESSION 的 ACK 和 DATA。

## 命令

| 方向 | CMD | Payload | 说明 |
| --- | ---: | --- | --- |
| STM32 -> Jetson | `0x01` | `period_ms:uint16` | 开始颜色检测 |
| STM32 -> Jetson | `0x02` | `period_ms:uint16` | 开始数字圆环检测 |
| STM32 -> Jetson | `0x03` | `period_ms:uint16` | 开始物料盘中心检测 |
| STM32 -> Jetson | `0x04` | 无 | 停止当前检测 |
| STM32 -> Jetson | `0x05` | `period_ms:uint16` | 开始一次二维码识别会话 |
| Jetson -> STM32 | `0x80` | `acked_cmd:uint8,status:uint8` | 命令确认 |
| Jetson -> STM32 | `0x81` | 目标列表 | 颜色结果 |
| Jetson -> STM32 | `0x82` | 目标列表 | 数字圆环结果 |
| Jetson -> STM32 | `0x83` | 盘中心结果 | 物料盘中心 |
| Jetson -> STM32 | `0x84` | `task_code:ASCII[15]` | 稳定二维码任务码 |

默认周期为 40 ms：STM32 的 `DETECT_DEFAULT_PERIOD_MS` 和 Jetson `DEFAULT_PERIOD_MS` 必须保持一致。`period_ms=0` 返回 `BAD_PERIOD`，不会替换当前任务。新 START 自动替换旧模式并重置高级跟踪状态。

ACK 状态：`OK=0`、`BAD_CMD=1`、`BAD_LENGTH=2`、`BAD_PERIOD=3`。

## 结果字段

颜色与圆环 Payload：`count:uint8`，随后是最多 8 项 `type:uint8,x:int16,y:int16,confidence:uint8,measured:uint8,support_count:uint8`。`type` 是对应 YOLO 模型的 `class_id`，由各模型标签表解释。`measured=0` 表示该点仅来自预测；最终到达判断不得仅依赖预测。

盘中心 Payload：`status:uint8,x:int16,y:int16,support_count:uint8,measured_count:uint8`。零支持点必须为 `NO_TARGET`，坐标 `0,0`；不得把图像中心当作有效中心。

二维码结果 Payload 为固定 15 字节 ASCII，例如 `156+123+516+231`。Payload 不包含字符串结束符、内部长度、状态或换行；STM32 在本地复制后补 `\0`。每个二维码会话中，Jetson 最多上报一次稳定结果。二维码阻塞读取的 2000 ms 超时是 STM32 本地行为，不属于线协议字段。

## 新鲜度与缓存

STM32 只保存每种结果的最新一帧，新数据直接覆盖旧数据，不排队。getter 仅在有尚未读取的新结果时返回 1。当前会话连续 200 ms 没有有效 DATA 时，STM32 停车并结束视觉阶段。
