# 03 通信协议与安全控制

## 目标

建立独立于 Jetson 通信的 USART1 二进制协议，并把任意位姿控制、STOP、心跳和错误处理纳入同一套状态机。

## 帧格式

```text
A5 5A | VERSION | CMD | SEQ | LEN_L LEN_H | PAYLOAD | CRC_L CRC_H
```

- CRC 使用 CRC16-CCITT-FALSE。
- 多字节整数和浮点数据使用 Little Endian。
- `SEQ` 用于匹配 ACK、检测丢帧和记录重试。
- 接收器必须支持半帧、粘包、坏 CRC、超长帧和未知命令后的重新找帧。

### 首版字段冻结

- `VERSION` 固定为 `1`；CRC 覆盖从 `VERSION` 到 `PAYLOAD` 的全部字节，初始值为 `0xFFFF`，多项式为 `0x1021`。
- `LEN` 最大为 96；协议总帧最大 105 字节。
- `float` 使用 IEEE 754 单精度小端序；位置单位为 mm、航向单位为 deg、线速度单位为 mm/s、角速度单位为 deg/s。

| 命令 | 值 | 请求 Payload | 成功响应 |
|---|---:|---|---|
| `GET_PID` | `0x01` | 空 | `PID`：版本号 `u32` + 六个 `float` |
| `SET_PID` | `0x02` | 六个 PID `float` | `ACK`：命令值 + 待生效版本号 `u32` |
| `RESTORE_PID` | `0x03` | 空 | `ACK`：命令值 + 待生效版本号 `u32` |
| `GOTO_POSE` | `0x10` | X/Y/yaw/vmax/wmax 五个 `float` + timeout `u32` + flags `u8` | `ACK`：命令值 |
| `STOP` | `0x11` | 空 | `ACK`：命令值 |
| `HEARTBEAT` | `0x12` | 空 | `ACK`：命令值 |

`GOTO_POSE` 固定使用 `CHASSIS_DEFAULT_ACC=10`，不开放电机加速度参数。调参模式额外拒绝超过 200 mm/s、90 deg/s 或 15 s 的目标；运行中再次发送 GOTO 返回 `BUSY`，必须先 STOP。

`ACK=0x80`、`PID=0x81`、`ERROR=0xE0`，响应帧复用请求 `SEQ`。ERROR payload 为请求命令值和错误码；错误码覆盖 CRC、版本、长度、未知命令、非法 PID、非法目标、忙、无原点、无位姿和位姿超时。重复的同一 `SEQ + CMD` 不重复执行业务，而是重发最近一次缓存响应。

## 命令集合

- `GET_PID`：读取当前生效参数和版本号。
- `SET_PID`：提交完整六参数组。
- `RESTORE_PID`：提交默认配置。
- `GOTO_POSE`：下发受边界和速度限制的 X、Y、yaw、超时和约束标志。
- `STOP`：取消当前目标并平滑停车。
- `HEARTBEAT`：维持远程控制会话。
- `START_TELEMETRY` / `STOP_TELEMETRY`：控制遥测流。

响应必须区分 ACK、PID、状态/遥测和 ERROR；错误至少覆盖参数非法、忙、CRC 错误、版本不支持、长度错误和未启用调参模式。

## 数据流与职责

```text
UART IDLE/DMA 回调
    → 只复制字节并记录接收长度
前台 CommTuner_Process()
    → 找帧、校验、解析命令
    → 调用 AdvanceMotion/参数接口
    → 排队 ACK 或 ERROR
TIM6 1 ms 调度
    → 更新心跳计时和发送标志
前台发送服务
    → 使用 USART1 TX DMA 发送，不阻塞控制周期
```

`CommTuner_Update()` 由 TIM6 每 1 ms 调用。成功 GOTO 自动建立远程会话；后续成功 HEARTBEAT 或 GOTO 刷新会话时间。超过 1500 ms 未刷新时，固件调用 `AdvanceMotion_Cancel()` 平滑停车并退出会话。

## 安全策略

- 远程运动期间上位机每 500 ms 发送一次心跳。
- 连续 1500 ms 未收到心跳时，取消远程目标并执行平滑停车。
- STOP 始终可见、可重复发送，不能因为串口忙而被永久隐藏。
- 任意位姿目标必须通过世界坐标边界、最大线速度、最大角速度和超时校验。
- GUI STOP 不是物理急停；现场必须保留机械急停、断电能力和人工监护。

## 验收标准

- Python 或十六进制串口工具可以完成 GET/SET/RESTORE/STOP。
- 任意位姿命令能得到 ACK 或明确 ERROR，不会静默失败。
- 断开上位机后 1500 ms 内停止远程运动。
- 解析和发送不在 UART 中断临界区执行耗时业务。
