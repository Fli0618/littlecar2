# PID 在线调参工具计划

## 目标

在 STM32 上完成一次调参固件烧录后，通过 USART1 在线修改整车位姿外环 PID，实时观察控制误差和速度响应，并保存可复现实验结果。首版面向 Windows 11，参数只保存在 STM32 RAM，上位机负责保存实验方案。

本目录是可执行的工程计划，不等同于已经完成的功能。所有里程碑初始状态均为“未开始”。

## 当前基线

- `Core/Inc/advance_motion.h` 当前仍以编译期宏提供六个 PID 参数。
- `AdvanceMotion_Update()` 由 TIM6 调度，控制周期为 20 ms。
- USART1 当前为 115200、8N1，已有 RX DMA；TX 仍需后续在 CubeMX 中配置 DMA。
- USART1 的 `fputc()` 发送是阻塞式接口，调参遥测不得复用 `printf`。
- USART6 继续用于 Jetson 通信，调参协议与 `comm_jetson` 保持职责隔离。
- `AdvanceMotion_RuntimeStatus_t` 已能提供基础运行状态，后续需要扩展控制输出和实测速度快照。

## 首版范围

- 开放 `Kp_pos`、`Ki_pos`、`Kd_pos`、`Kp_yaw`、`Ki_yaw`、`Kd_yaw`。
- 支持运动中提交完整参数组，在下一个 20 ms 控制周期边界整体生效。
- 支持读取参数、恢复默认、任意位姿测试目标、STOP、心跳和遥测启停。
- 不调整 ZDT 电机内部 PID、视觉对准参数和机械臂参数。
- 不把参数写入 STM32 Flash；上位机使用 JSON 保存参数方案，使用 CSV 保存实验记录。

## 总体验收

1. 调参固件能通过 USART1 稳定接收命令，比赛主流程不在调参模式中运行。
2. 六个参数能整组校验、在线生效，生效过程不会读到半组参数。
3. 上位机能读取、修改、恢复参数，发送任意受限位姿目标并执行 STOP。
4. 遥测连续运行 30 秒，CRC、序号、丢帧和重连行为可统计。
5. GUI 不阻塞，曲线持续刷新，参数修改和事件标记可追溯。
6. 先完成悬空和低速测试，再进行单轴、双轴和联合运动测试。
