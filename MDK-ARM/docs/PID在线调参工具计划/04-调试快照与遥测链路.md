# 04 调试快照与遥测链路

## 目标

输出足以解释 PID 行为的数据，而不是只显示目标位置和实际位置。

## 快照字段

每个 20 ms 控制周期更新一次快照，至少包括：

- tick、运行状态和参数版本号。
- target/actual/error：X、Y、yaw。
- command velocity：`vx`、`vy`、`wz`。
- measured velocity：`vx`、`vy`、`wz`。
- 三轴积分项。
- 线速度饱和、角速度饱和和数据新鲜度标志。

快照写入控制状态时保持结构体一致性；读取时使用短临界区复制，临界区内不得发送 UART。

## 遥测策略

- 首版固定 25 Hz 遥测，即每两个 20 ms 控制周期发送一帧。
- 使用 USART1 TX DMA，禁止 `printf` 和阻塞式 `HAL_UART_Transmit()`。
- DMA 忙时保留最新快照，允许丢弃旧快照，不允许堆积无限发送队列。
- 每帧携带序号和 tick，便于上位机统计丢帧、延迟和重连。

## 已实现协议

- `TELEMETRY` 的命令值为 `0x82`，是 STM32 主动发送的帧，不需要上位机订阅。
- 仅当 USART1 发起的 `GOTO_POSE` 仍处于 `RUNNING` 状态时发送；成功 GOTO 后开始，STOP、到达、超时、失联或异常结束后停止。
- 发送周期固定为 40 ms（25 Hz）。普通 ACK、PID 和 ERROR 响应优先于遥测帧；DMA 忙时仅保留最新遥测，覆盖次数写入后续遥测帧。
- Payload 固定 88 字节，均为 Little Endian：

| 偏移 | 类型 | 字段 |
|---:|---|---|
| 0 | `u32` | `tick` |
| 4 | `u32` | PID 修订号 |
| 8 | `u32` | 遥测覆盖计数 |
| 12 | `u8` | 运行状态 |
| 13 | `u8` | 标志位：有效、位置新鲜、航向新鲜、线速度限幅、角速度限幅 |
| 16 | `float[3]` | 目标 `x/y/yaw` |
| 28 | `float[3]` | 实际 `x/y/yaw` |
| 40 | `float[3]` | 误差 `x/y/yaw` |
| 52 | `float[3]` | 命令速度 `vx/vy/wz` |
| 64 | `float[3]` | 实际速度 `vx/vy/wz` |
| 76 | `float[3]` | PID 积分项 `x/y/yaw` |

## 硬件前置条件

当前工程仅有 USART1 RX DMA。USART1 TX DMA、DMA Stream/Channel、NVIC 优先级和 CubeMX 生成代码必须由用户在 CubeMX 中完成，本次不直接编辑 `.ioc` 或生成文件。

## 异常处理

- 快照读取失败或数据过期时，遥测帧标记无效，不发送伪造零值。
- TX DMA 忙时只保留最新帧，并递增丢帧计数。
- UART 错误后重新启动接收，不阻塞控制器。

## 验收标准

- 30 秒遥测中 CRC 全部正确，丢帧数量可统计。
- 控制周期无明显抖动，发送队列不会持续增长。
- STOP、到达、超时和失联后的速度指令符合安全预期。
