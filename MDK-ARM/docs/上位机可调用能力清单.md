# Jetson 视觉服务能力清单

Jetson 不再是 STM32 的主控客户端。它仅接收 STM32 视觉任务并持续返回数据，不能下发底盘、机械臂、OPS 或 WIT 指令。

| STM32 命令 | Jetson 行为 | 返回数据 |
| --- | --- | --- |
| `0x01` 颜色 START | 连续调用 `advance_detect_color` | `0x81` 目标列表 |
| `0x02` 圆环 START | 连续调用 `advance_detect_circle` | `0x82` 目标列表 |
| `0x03` 盘中心 START | 连续调用 `advance_detect_disk_center` | `0x83` 中心结果 |
| `0x04` STOP | 立即停发、重置跟踪，保持服务和模型可用 | `0x80` ACK |

完整帧格式、结果字段、状态码与 SESSION 规则见 [上下位机通信协议](上下位机通信协议.md)。
