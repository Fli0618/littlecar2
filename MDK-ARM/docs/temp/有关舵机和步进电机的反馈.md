# 舵机与步进电机反馈现状

更新时间：2026-07-23。

## 驱动层反馈

- `drive_emm` 保留 USART3 DMA/IDLE 回包解析、反馈缓存和底盘反馈监督能力。
- 总线舵机仍只实现位置命令发送；反馈接口保留在驱动层，但当前不参与机械臂高层动作。

## 机械臂高层策略

`advance_arm` 是固定参数的阻塞模块。升降轴注册步进电机反馈并使用顶部单光电建立零点，以 `ARM_LIFT_POS_MAX` 实施软件行程限制；滑台使用人工软件零点、反馈和 `ARM_SLIDE_POS_MAX`，不读取光电；总线舵机仍为位置命令加固定等待。

- 升降归零：顶部光电已触发时先低速释放，再向顶部搜索并稳定确认；清零命令完成后才允许升降绝对位置运动。
- 升降运动：朝零点运动时检查顶部光电，远离零点时不读取远端限位；反馈失效、堵转、故障或超时会停止并清除归零状态。
- 滑台运动：使用软件零点和 `ARM_SLIDE_POS_MAX`，不读取 `LIFT_DOWN_LIMIT_*`、`SLIDE_FRONT_LIMIT_*` 或 `SLIDE_REAR_LIMIT_*`。
- 夹爪、旋转和物料盘舵机：忽略发送结果后固定等待 `ARM_SERVO_MOVE_DELAY_MS`。
- `ARM_PICK`：伸出、下降、闭合夹爪、上升、收回。
- `ARM_PLACE`：伸出、下降、打开夹爪、上升、收回。

Pick/Place 正常流程约阻塞 5000 ms。固定等待不代表电机已经实际到位。

## 上位机协议

| CmdID | 命令 | 当前行为 |
| ---: | --- | --- |
| `0x10` | `ARM_GRAB` | 仅接受 1 字节开合标志，同步阻塞 1000 ms |
| `0x12` | `ARM_PICK` | 仅接受空 Payload，同步执行固定抓取流程 |
| `0x13` | `ARM_PLACE` | 仅接受空 Payload，同步执行固定放置流程 |
| `0x14` | `ARM_ABORT` | 仅接受空 Payload，停止两步进轴 |
| `0x11`、`0x15`、`0x16` | `ARM_CONFIG`、`ARM_GET_STATUS`、`ARM_RESET_ZERO` | 返回 `ACK_UNKNOWN_CMD` |

机械臂动作开始前 STM32 会停止底盘并刷新当前控制者心跳；ACK 在阻塞动作结束后发送。`ACK_OK` 只表示阻塞函数返回，不代表机构实际到位。阻塞期间普通协议不能立即中断当前动作。

## 上板验收

1. 在无碰撞风险条件下确认升降轴和滑台轴方向，并完成顶部光电归零验证。
2. 验证顶部光电已触发、未触发、失效和始终触发时的释放、搜索、超时与归零状态。
3. 标定 `ARM_LIFT_POS_MAX`、升降固定点位和 `ARM_SLIDE_POS_MAX`，再验证舵机固定等待与物料动作顺序。
