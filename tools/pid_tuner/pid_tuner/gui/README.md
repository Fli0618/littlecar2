# GUI 模块

该目录实现 PySide6 与 pyqtgraph 调参界面。串口协议仅通过上层 `SerialClient` 访问；Qt 主线程以 40 ms 定时器批量刷新曲线。图表按轴拆分为 OPS 世界坐标 X、OPS 世界坐标 Y、WIT 相对航向、OPS 相对 Z 航向；每个航向行显示共享目标角、对应实际角和角度误差。界面支持组合、位置、角度三类 GOTO，以及运行时 WIT/OPS 航向 PID 数据源切换和零点重置。
# 心跳保活

GOTO 确认后，GUI 以 250 ms 周期发送心跳。心跳请求在途时不会再次排队；STOP、运动终态、断开连接或心跳失败会停止保活。
# 分辨率适配

控制区和四行图表区各自使用滚动容器：窗口高度或宽度不足时保持控件与图表的最小可读尺寸，通过滚动查看完整内容，不压缩字体或绘图区。
