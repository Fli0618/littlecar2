# 底盘运动调试工作台

该工具在一个 PySide6 窗口中组合现有 PID 调参、地图编辑和连续路径调试能力。它不直接访问串口；所有通信都经由 `pid_tuner` 的单一 `SessionController`。

开发环境依次安装三个本地包：

```powershell
pip install -e tools/pid_tuner
pip install -e tools/map_planner
pip install -e tools/motion_workbench
```

启动命令：`motion-workbench`；也可在本目录执行 `python launch_gui.py`。

连续路径使用协议 V2 的扩展命令，要求 STM32 已刷入对应固件。单条路径最多 256 个 `x/y/yaw` 点；工作台在上传前拒绝超限路径。

地图的“显示交换 X/Y”和“显示反转 X/Y”统一控制地图坐标系：实测车辆、轨迹和误差使用正向变换，单点 GOTO、地图流程及连续路径在下发前使用逆变换，原始遥测和已保存方案保持不变。交换和 X/Y 反转每次启动均默认关闭；车辆航向随方向向量同步变换。单步执行始终运行当前选中动作，可重复点击；连贯执行从当前选中动作开始。

窗口右上角提供“重置零点”和“返回零点”：两者仅在串口已连接且车辆空闲时启用。重置成功后清空旧坐标系轨迹并将候选目标归零；返回零点沿用单点页当前速度、角速度、超时和航向约束设置，并使用当前地图坐标变换下发。

"路径"页可在线读取、整组应用或恢复连续路径参数，包括横向/航向 PD、速度与加速度规划、动态前视。新参数由 STM32 在 20 ms 控制周期边界切换，活动路径的进度不会被清空。

“单点”页的“航向控制模式”可选择 `WIT yaw`、`OPS yaw` 或“不使用航向”。WIT/OPS 会通过现有调参协议切换 STM32 航向源；不使用航向时，位置 GOTO 会清除 `GOAL_USE_YAW` 标志，WIT/OPS 数据仍保留在图表中作为对照。误差图会标注当前值、零线以及当前控制源/对照源/未参与控制。

“PID”和“路径”页的参数框不会响应鼠标滚轮，避免滚动页面时误改数值。双击框内数值后才能键盘输入，按回车或移开焦点后自动重新锁定；右侧上下按钮仍可按设定步长调整。

地图执行前必须完成起点标定并执行 ResetOrigin。工作台在收到接近世界零点的有效遥测后才将坐标状态标为“正常”；起点变化、超时或遥测偏差会使地图执行重新锁定。路径只有收到 PATH_COMMIT 确认后才可启动。

## 固化运动控制参数

工作台顶部的“导出固化参数”仅在当前串口连接已完成 PID、路径控制参数和 GOTO 默认策略三类同步后启用。导出内容来自 STM32 已确认生效的活动配置，而不是当前输入框；修改输入框但未应用时不会改变导出结果。

导出文件完整包含 6 项单点位姿 PID、20 项连续路径控制参数和 1 项 GOTO 默认策略。可在预览窗口复制全部或另存为 `advance_motion_config.h`，然后替换 STM32 工程中的 `Core/Inc/advance_motion_config.h`，重新编译并烧录。

该功能不写入 STM32 Flash，不属于掉电参数持久化。工作台中的“恢复默认”会恢复当前固件由 `advance_motion_config.h` 编译得到的默认值。
路径参数旧说明中的“14 项”已废止；当前实际模型与调参协议均为 20 项。
