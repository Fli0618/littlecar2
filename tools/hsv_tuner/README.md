# HSV 调参工具

本目录统一管理离线 HSV 阈值调参工具。工具只读取图片和 HSV 配置，不访问相机、串口、YOLO 或 TensorRT。正式入口是 Tkinter 图形界面，不使用 CLI 参数。

先在仓库根目录安装项目依赖：

```powershell
python -m pip install -e jetson
```

从仓库根目录运行图形界面：

```powershell
python tools/hsv_tuner/hsv_tuner_gui.py
```

启动窗口后选择图片目录或单张图片、HSV 配置和导出目录。界面提供四宫格预览、HSV 三通道直方图、H-S 二维热力图、ROI 框选、像素采样、阈值线、配置保存和 Mask/预览导出。默认配置为 `jetson/assets/config/hsv_colors.json`。输出目录和缓存文件不应提交。

主界面左侧为可响应式正方形四宫格，右侧为颜色阈值、处理与采样、统计诊断页签。默认分析分辨率为部署契约 `640×480`，也可切换到原始分辨率；分类和图表只统计 ROI 中心椭圆，不选择 ROI 时不会进行整图分类。ROI 坐标会在原图、分析图和 Canvas 之间保持映射，点击留白不会被吸附到边缘。

导出使用 Unicode 安全写入，四宫格输出尺寸为 `2*tile_size + gap`。第三组及以后 HSV 区间在工具中只读保留，关闭第二组时不会覆盖第二组配置。

颜色页的“一键推荐当前颜色”只基于当前 ROI 的正式中心椭圆生成工作配置，支持红色 H=0/179 跨界双区间，并显示前景覆盖率、背景泄漏率和颜色冲突率。推荐值不会自动保存，可撤销；保存前应切换其他图片验证。

启动时会自动导入项目默认配置。编辑器支持导入默认参数、导入外部 JSON、重载当前配置、保存和另存为。保存默认配置后，需要重启 Jetson 视觉服务，新的 HSV 参数才会进入正式 YOLO bbox + HSV 分类链路。
