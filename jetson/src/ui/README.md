# 比赛显示界面

`competition_gui.py` 提供基于 Tkinter 的普通比赛窗口，只负责显示和用户点击事件。

界面不直接访问串口、摄像头或视觉模型；这些资源仍由 `jetson/main.py` 统一管理。
中文控件统一从 Tk 已注册字体中选择 Noto CJK、WenQuanYi、Droid Sans Fallback
或 Microsoft YaHei；候选均不可用时使用 Tk 实际默认字体，不返回不存在的字体名称。

## 场地标注页

开始页左下角的“场地标注”按钮进入静态场地说明页。该页由 Canvas 以 `2400 mm × 2400 mm` 逻辑坐标等比绘制场地、关键尺寸和区域名称，不使用场地示意图文件，也不发送比赛命令或改变计时、任务码和统计值。左上角“返回”按钮及 Esc 键返回开始页。
